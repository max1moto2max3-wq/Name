# MediaPro Studio

تطبيق Android أصلي لتحرير الصور والفيديو باستخدام Kotlin وJetpack Compose وMaterial 3. التطوير مستمر، ولا تُعد هذه النسخة إصداراً نهائياً.

## التقنية
- Kotlin 2.0.21 وAndroid Gradle Plugin 8.7.3 وJDK 17.
- Jetpack Compose وMaterial 3 وNavigation Compose.
- MVVM وStateFlow وHilt.
- Room لتخزين بيانات المشاريع.
- Media3 ExoPlayer وTransformer لمعاينة الفيديو وقصه.
- Photo Picker لاستيراد الملفات، مع نسخ الوسائط المستوردة إلى مساحة التطبيق الخاصة لضمان استمرار الوصول إليها بعد إعادة تشغيل التطبيق.

## الوظائف المنفذة حالياً
- واجهة عربية وتنقل بين الرئيسية والمشاريع والإعدادات.
- استيراد الصور والفيديو والاحتفاظ بنسخة داخل مساحة التطبيق.
- حفظ بيانات المشاريع محلياً باستخدام Room.
- معاينة الصور وتعديل السطوع والتباين والتشبّع.
- تدوير الصور، والقص المركزي بنسب 1:1 و4:5 و16:9، وإضافة نص على الصورة.
- تصدير نسخة JPEG إلى Pictures/MediaProStudio دون تعديل الأصل.
- معاينة الفيديو مع شريط تنقل زمني قابل للسحب، وتحديد نطاق القص، وتصدير MP4 إلى Movies/MediaProStudio.
- التحقق من صلاحية نطاق القص قبل بدء التصدير.
- اختبارات وحدات أولية لنموذج نطاق قص الفيديو.

## أعمال ما زالت مطلوبة قبل الإصدار
- محرر صور أوسع: قص حر ونسب أبعاد متعددة، تغيير الحجم، أدوات الرسم، طبقات نص وصور قابلة للتحريك والتنسيق، فلاتر قابلة للتعديل، وإدارة التراجع/الإعادة.
- محرر فيديو متعدد المسارات: إضافة وترتيب ودمج عدة مقاطع، قص وتقسيم دقيق، انتقالات، طبقات نص وصور، تحكم بالصوت ومستويات الصوت، وسرعة التشغيل.
- حفظ إعدادات التحرير ومخطط المشروع واستعادتهما، لا الاكتفاء بحفظ مصدر الوسائط.
- مهام تصدير موثوقة في الخلفية مع تقدم وإلغاء واستعادة بعد إغلاق التطبيق.
- معالجة ملفات كبيرة، اتجاه EXIF، الذاكرة، التنسيقات والترميزات غير المدعومة.
- اختبارات وحدات وتكامل وواجهة، ثم تحقق على أجهزة Android فعلية وإصدارات متعددة.

## التحقق والبناء
- تشغيل اختبارات الوحدة تلقائياً عند الدفع أو فتح Pull Request.
- بناء APK مؤجل إلى تشغيل يدوي لسير عمل الإصدار بعد اكتمال الميزات والتحقق.
- لا يُعلن عن إصدار APK على أنه جاهز قبل نجاح اختبارات النسخة المطابقة لآخر commit، ومراجعة artifact الناتج.
- لم يُثبت بعد اختبار التطبيق على جهاز Android فعلي.

## متطلبات التطوير
- Android Studio حديث يدعم AGP 8.7.3.
- JDK 17 وAndroid SDK 35.
- الحد الأدنى Android 10 (API 29).
