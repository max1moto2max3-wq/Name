# MediaPro Studio

تطبيق Android أصلي لتحرير الصور والفيديو، قيد التطوير باستخدام Kotlin وJetpack Compose وMaterial 3.

## التقنية
- Kotlin 2.0.21 وAndroid Gradle Plugin 8.7.3، مع JDK 17.
- Jetpack Compose وMaterial 3 وNavigation Compose.
- MVVM وStateFlow وHilt.
- Room لتخزين قائمة المشاريع محلياً.
- Coil لمعاينة الصور.
- Android Photo Picker لاستيراد الصور والفيديو.
- Media3 ExoPlayer وTransformer لمعاينة الفيديو وقص مقطع.

## متطلبات البناء
- Android Studio حديث يدعم AGP 8.7.3.
- JDK 17 وAndroid SDK 35.
- الحد الأدنى Android 10 (API 29).

## ما يعمل في المرحلة الحالية
- شاشة رئيسية عربية والتنقل بين الرئيسية والمشاريع والإعدادات.
- استيراد الصور والفيديو عبر منتقي النظام.
- حفظ بيانات المشاريع محلياً باستخدام Room.
- محرر صور أولي لمعاينة الصورة وتعديل السطوع والتباين والتشبّع.
- تصدير نسخة JPEG إلى Pictures/MediaProStudio دون تعديل الملف الأصلي.
- معاينة الفيديو عبر Media3 ExoPlayer، تحديد نقطة البداية والنهاية، وتصدير مقطع MP4 إلى Movies/MediaProStudio عبر Transformer.

## ما لم يكتمل بعد
- timeline متعدد المسارات، دمج عدة مقاطع، الانتقالات والمؤثرات والصوت.
- أدوات قص الصور والطبقات والنصوص وLUT وميزات AI.
- حفظ حالة تعديلات كل مشروع واستعادتها.
- تصدير الفيديو عبر مهمة خلفية طويلة الأمد، اختبارات واجهة ومقاييس الأداء على أجهزة فعلية.

هذه نسخة تطويرية وليست محرراً احترافياً مكتملاً؛ تضاف الميزات على مراحل وتخضع للبناء والاختبار.
