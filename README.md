# لَمْعَة — React Native

تطبيق لَمْعَة مبني بواجهة React Native باستخدام Expo، مع واجهة عربية RTL وتصميم داكن.

## التشغيل محلياً

- Node.js 20 أو أحدث
- Android Studio و Android SDK
- تثبيت الاعتماديات: `npm install`
- تشغيل خادم التطوير: `npx expo start`
- تشغيل Android: `npx expo run:android`

## المتوفر حالياً

- واجهة React Native عربية باتجاه RTL.
- اختيار صورة أو فيديو من مكتبة الجهاز.
- معاينة الصور والفيديو وتشغيل الفيديو.
- تدوير الصورة وقلبها أفقياً ورأسياً.
- حفظ نسخة JPEG من الصورة بعد تطبيق التحويلات إلى معرض الجهاز.

## قيد التطوير

عناصر الإضاءة والتباين والتشبّع ظاهرة كواجهة أولية فقط ولا تُطبّق على الصورة المحفوظة بعد. أدوات القص والطبقات والنصوص والفلاتر الفعلية وتحرير الفيديو وتصديره ليست مكتملة بعد.

## البناء

GitHub Actions ينشئ مشروع Android الأصلي عبر Expo Prebuild ثم يبني Debug APK. نجاح البناء الآلي لا يغني عن اختبار التطبيق على جهاز فعلي.
