# لَمْعَة — استوديو الصور والفيديو

محرر صور وفيديو عربي يعمل مباشرة في المتصفح، بواجهة RTL داكنة ومتجاوبة. ملفاتك تبقى محلياً على جهازك ولا تُرفع إلى أي خادم.

## التشغيل

افتح `index.html` في متصفح حديث، أو انشر المستودع على GitHub Pages لاستعماله كرابط مباشر. لا يحتاج المشروع إلى تثبيت حزم أو إعداد خادم.

## الميزات

- استيراد الصور والفيديو بالسحب والإفلات أو من مستعرض الملفات.
- معاينة الصور والفيديو، مع عناصر تشغيل الفيديو والبحث والسرعة.
- ضبط الإضاءة والتباين والتشبّع والدفء والتعتيم، وفلاتر جاهزة.
- تدوير الوسائط وقلبها أفقياً أو عمودياً.
- تصدير الصور بصيغ PNG وJPEG وWEBP مع التحكم بالجودة.
- قص نطاق فيديو وتصديره إلى WebM عبر تسجيل المعاينة على جهازك.
- واجهة عربية متجاوبة مع الهاتف والحاسوب.

## ملاحظة التوافق

تصدير الفيديو يعتمد على `MediaRecorder` و`canvas.captureStream`، لذلك يتطلب متصفحاً حديثاً. صيغة الفيديو المصدرة WebM؛ يعتمد دعم صوت المصدر على دعم المتصفح لالتقاط مسار الصوت من عنصر الفيديو. لا توجد عملية بناء أو اعتماديات خارجية مطلوبة.
