# لَمْعَة — استوديو Android الأصلي

تطبيق تحرير وسائط Android أصلي بواجهة Kotlin وواجهات Android القياسية. لا يستخدم WebView ولا HTML ولا JavaScript.

## البناء
- Android Studio مع Android Gradle Plugin 8.7.3
- JDK 17 وGradle 8.9
- minSdk 24 / compileSdk 35

## المتوفر في إعادة البناء الأصلية
- واجهة عربية RTL بتصميم داكن حديث.
- استيراد الصور والفيديو من منتقي الوسائط الأصلي.
- معاينة الفيديو وتشغيله بعناصر تحكم Android.
- معاينة الصور مع ضبط الإضاءة والتباين والتشبّع.
- تدوير الصور وقلبها أفقياً ورأسياً.
- تصدير الصور المعدّلة بصيغة JPEG إلى Pictures/Lamah.
- معالجة الصور محلياً على الجهاز.

## ما لم يكتمل بعد
هذه قاعدة Android الأصلية الجديدة وليست بعد محرر فيديو احترافياً كاملاً. قص الفيديو، ودمج المقاطع والمسارات، والمؤثرات والطبقات والنصوص وتصدير الفيديو ميزات لاحقة. لا تعرض النسخة الحالية هذه الوظائف على أنها مكتملة.

## التحقق
GitHub Actions يبني نسخة Debug APK تلقائياً. نجاح البناء لا يغني عن اختبار التطبيق على أجهزة Android فعلية بمقاسات وإصدارات مختلفة.
