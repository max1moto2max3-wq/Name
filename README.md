# لَمْعَة — استوديو الصور والفيديو

محرر عربي للصور والفيديو يعمل محلياً على جهاز المستخدم. يتضمن واجهة RTL داكنة ومتجاوبة، ويمكن تشغيله في المتصفح أو كتطبيق Android.

## تطبيق Android

تمت إضافة مشروع Android أصلي بلغة Kotlin، يستخدم WebView لتشغيل محرر لَمْعَة المضمّن دون خادم أو رفع ملفات.

### البناء

1. افتح المستودع في Android Studio (إصدار يدعم Android Gradle Plugin 8.7.3).
2. استخدم JDK 17.
3. نفّذ Gradle Sync.
4. شغّل وحدة `app` على جهاز Android أو أنشئ APK من Build > Build Bundle(s) / APK(s) > Build APK(s).

الحد الأدنى Android 7.0 (API 24)، وهدف البناء API 35.

## الميزات الحالية

- استيراد عدة صور وفيديوهات من منتقي ملفات Android.
- معاينة الصور والفيديو والتحكم بالتشغيل والبحث والسرعة.
- ضبط الإضاءة والتباين والتشبّع والدفء والتعتيم.
- فلاتر أصلية، عتيقة، سينمائية، حالمة وأبيض وأسود.
- تدوير الوسائط وقلبها أفقياً وعمودياً.
- إضافة عناوين وعلامات مائية للنص على الصور والفيديو، مع اختيار اللون والحجم والموضع، ودمجها في الملف المُصدّر.
- تصدير الصور بصيغ PNG وJPEG وWEBP مع التحكم بالجودة.
- عرض ملفات المشروع كمسارات مستقلة في الخط الزمني، مع اختيار المسار وإعادة ترتيب المسارات وإظهار/إخفاء مسار النص.
- قص نطاق فيديو وتصديره إلى WebM عبر MediaRecorder وcanvas في WebView المتوافق.
- معالجة محلية؛ لا توجد واجهة خلفية ولا رفع للملفات.

## تشغيل نسخة الويب

افتح `index.html` في متصفح حديث، أو انشر المستودع على GitHub Pages.

## ملاحظات تقنية

- منطق التحرير والواجهة مكتوبان بـ HTML وCSS وJavaScript؛ غلاف Android أصلي بـ Kotlin.
- تصدير الفيديو يعتمد على دعم WebView لـ `MediaRecorder` و`canvas.captureStream`، وقد يختلف حسب إصدار Android والجهاز. صيغة الفيديو الناتجة WebM.
- المسارات المتعددة الحالية تنظّم ملفات المشروع وتتيح التنقل بينها؛ لا تدمج بعد عدة مقاطع في فيديو مركّب واحد، ولا يتوفر تصدير MP4 أصلي.
- ملف `app/src/main/assets/index.html` مطلوب حالياً لأنه يحتوي واجهة المحرر ومنطق التحرير الذي يشغّله غلاف Android عبر WebView؛ لا تحذفه ما لم يُنقل المحرر بالكامل إلى واجهة Android أصلية.
- سير عمل GitHub Actions يفحص صياغة JavaScript المضمّن ويحاول بناء نسخة Android Debug تلقائياً.
