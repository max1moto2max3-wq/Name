# MediaPro Studio

تطبيق Android أصلي لتحرير الصور والفيديو باستخدام Kotlin وJetpack Compose وMaterial 3. المشروع قيد التطوير، ولا تُعد النسخة الحالية إصداراً نهائياً.

## التقنية
- Kotlin وAndroid Gradle Plugin وJDK 17.
- Jetpack Compose وMaterial 3 وNavigation Compose.
- MVVM وStateFlow وHilt.
- Room لتخزين بيانات المشاريع.
- Media3 ExoPlayer وTransformer لمعاينة الفيديو وقصه.
- Photo Picker لاستيراد الملفات، مع نسخ الوسائط المستوردة إلى مساحة التطبيق الخاصة.

## الصفحات الحالية
- الرئيسية: استيراد الصور والفيديو وعرض المشاريع الأخيرة.
- مركز الأدوات: تصنيف أدوات الصور والفيديو والصوت والتصميم والتصدير، مع تمييز الأدوات المتاحة عن المخطط لها.
- المشاريع: عرض المشاريع المحفوظة وفتحها وحذفها مع تأكيد.
- الإعدادات: صفحة الإعدادات الأساسية.
- محرر الصور ومحرر الفيديو: صفحات تحرير مستقلة.

## الوظائف المنفذة حالياً
- استيراد الصور والفيديو والاحتفاظ بنسخة داخل مساحة التطبيق.
- حفظ بيانات المشاريع محلياً باستخدام Room.
- معاينة الصور وتعديل السطوع والتباين والتشبّع.
- تدوير الصور، والقص المركزي بنسب 1:1 و4:5 و16:9، وإضافة نص على الصورة.
- تصدير نسخة JPEG إلى Pictures/MediaProStudio دون تعديل الأصل.
- معاينة الفيديو مع شريط تنقل زمني قابل للسحب، وتحديد نطاق القص، وتصدير MP4 إلى Movies/MediaProStudio.
- التحقق من صلاحية نطاق القص قبل بدء التصدير.
- حذف سجل المشروع ونسخة الوسائط المستوردة التابعة له فقط.
- اختبارات وحدات أولية لنموذج نطاق قص الفيديو.

## خارطة تطوير الأدوات
### الصور
- قص حر، تغيير الحجم، قلب الصورة، تدوير دقيق، وتصحيح المنظور.
- أدوات الرسم والفرشاة والممحاة والأشكال.
- طبقات نصوص وملصقات وصور مع التحريك والتدوير وتغيير الحجم.
- فلاتر قابلة للتعديل، منحنيات الألوان، توازن اللون الأبيض، HSL، وإزالة العين الحمراء.
- التراجع والإعادة وسجل التعديلات.

### الفيديو
- خط زمني متعدد المسارات وإضافة وترتيب ودمج المقاطع.
- القص والتقسيم الدقيق، والانتقالات، وتغيير السرعة.
- طبقات النصوص والصور والملصقات والترجمة.
- التحكم بمستوى الصوت، كتم الصوت، التلاشي الصوتي، وإضافة مسارات صوتية.
- إعدادات تصدير للدقة ومعدل الإطارات والجودة.

### أدوات إضافية مقترحة
- محرر صوت مستقل ومحول تنسيقات.
- صانع الصور المصغرة وقوالب منشورات التواصل.
- ضغط الصور والفيديو وتغيير المقاسات دفعة واحدة.
- ماسح مستندات وتحويل الصور إلى PDF.
- إدارة الخطوط والألوان والعناصر المفضلة.
- قوالب مشاريع وحفظ الإعدادات المسبقة.
- مهام تصدير في الخلفية مع التقدم والإلغاء.
- دعم النسخ الاحتياطي واستعادة المشاريع.

الأدوات التي تظهر بحالة «قريباً» في مركز الأدوات هي عناصر مخطط لها وليست وظائف مكتملة.

## أعمال مطلوبة قبل الإصدار
- حفظ إعدادات التحرير ومخطط المشروع واستعادتهما.
- تنفيذ الأدوات المخطط لها واختبار كل أداة عملياً.
- معالجة الملفات الكبيرة والذاكرة والتنسيقات والترميزات غير المدعومة.
- اختبارات وحدات وتكامل وواجهة، ثم تحقق على أجهزة Android فعلية وإصدارات متعددة.

## التحقق والبناء
- سير عمل GitHub Actions يشغّل فحوص Kotlin واختبارات الوحدة عند الدفع أو فتح Pull Request.
- بناء APK للإصدار يتطلب تشغيل سير العمل يدوياً بعد اجتياز الاختبارات.
- لا يُعلن عن APK على أنه جاهز قبل نجاح البناء للـ commit المطابق ومراجعة artifact الناتج.
- لم يُثبت بعد اختبار التطبيق على جهاز Android فعلي.

## متطلبات التطوير
- Android Studio حديث يدعم AGP 8.7.3.
- JDK 17 وAndroid SDK 35.
- الحد الأدنى Android 10 (API 29).
